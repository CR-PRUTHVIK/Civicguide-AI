# CivicGuide AI 🇮🇳

CivicGuide AI is an intelligent government services information assistant designed to help users find information about government services, schemes, eligibility, documents, and other civic-related queries.

## Features

- 🤖 AI-powered question answering
- 🔍 Retrieval-Augmented Generation (RAG)
- 📚 Searches relevant government information
- 💬 Interactive chat-style user interface
- 🧠 Context-aware responses
- ⚡ FastAPI backend
- 🎨 Modern responsive frontend
- 🗂️ Chat history management

## Technologies Used

- Python
- FastAPI
- Generative AI
- RAG (Retrieval-Augmented Generation)
- ChromaDB
- HTML
- CSS
- JavaScript
